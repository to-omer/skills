# HTML 文書の検証

原資料、ソース、実表示を確認し、機能の検証は実際に採用したものに絞る。

## 原資料と照合する

変換元がある場合は、見出し、リンク、表、図、コード、数式、重要な数値を原資料と照合し、その後で本文を通読する。

内容編集を伴う場合は、変更箇所がユーザーの指定した範囲に収まっているか確認する。

追加した図や操作について、数値、単位、尺度、条件、手順、状態の対応を元資料と照合する。例や仮定を実測のように示していないか、段階的に開示する内容を先に見せていないか確認する。

## ソースを確認する

HTML パーサーやブラウザーの開発者ツールを使い、構文エラー、重複した `id`、存在しないページ内リンク、CSS や JavaScript の誤った参照、仮データやデバッグ情報を確認する。

文書構造は [文書構造](readability-and-layout.md#文書構造) を基準に確認する。複数の SVG と明暗別の図でも ID と内部参照が衝突しないことを確認する。

## ブラウザーで表示する

生成した HTML をブラウザーで開き、初期表示から処理完了までを見る。コンソールやネットワークのエラーも確認する。

狭い幅、標準的な幅、広い幅と、文字を拡大した状態で、[読みやすさとレイアウト](readability-and-layout.md) に照合する。想定画面の指定がない場合は、320〜390px、768px、1440px 程度を代表例にできる。

- ライト・ダークの両方で本文、補助文字、コード、図の文字と背景を読む
- 段落、短い強調、注釈、数式、コードが並ぶ画面で明るさと読み分けを確認し、文字と実際の背景のコントラストを測る
- ページ全体が横にはみ出さず、表・コード・数式の端まで局所スクロールできることを確認する
- 図を画面幅へ縮めた結果、図内の文字まで小さくなっていないか測定・目視する
- 実際の印刷ページを PDF などへ出し、図、コード、数式、ページの区切り、白地の配色と補足の開閉を確認する

印刷は背景グラフィックなしでも確認する。凡例の記号が消えないか、コマンドと条件が別ページになっていないか、大きな空白がないかを見る。画面上で印刷 CSS を適用した表示だけでは、改ページの確認を済ませない。

## 採用した機能を確認する

操作機能は実際に操作し、キーボードでも利用できることを確認する。値を変更する機能は、初期値と代表的な変更に加え、その用途で問題になりうる境界条件を試す。

数式は KaTeX の HTML 出力、元 TeX、読み上げ名、原式との意味の一致を確認する。MathJax、MathML、未処理の式や描画エラーが残っていないかを見る。代表的な式の使用フォントと、分数・上付き・下付きの組み方も調べる。

コードと差分は元の文字列と照合し、構文色、追加・削除、行の対応が意図どおりか確認する。差分では、行と語句の強調背景が重なる箇所についても、構文色や `+` / `-` のコントラストをライト・ダーク・印刷で確認する。日本語などを含む場合は実際の字形を見て、等幅の英数字とともに読めることを確認する。コピー機能では元のコードだけがコピーされることを確認する。

外部ライブラリがある場合は、指定したバージョンが読み込まれ、初期化処理が正しい順序で実行されることを確認する。

JavaScript を無効にしても主要な本文・図・コード・数式が読め、動かない操作欄が残らないことを確認する。オフライン対応が指定されている場合は、外部通信を遮断した状態でも確認する。

### ナビゲーションと文書操作

採用した機能について、[操作条件](navigation-and-controls.md) と照合する。

| 機能 | 確かめる結果 |
| --- | --- |
| タブ | 全区分・全文表示で欠落や重複がなく、キーボードの選択とフォーカスが整合する。JavaScript 無効時は全文と通常のページ内リンクを使える |
| 末尾の前後移動 | 長い区分の末尾から隣の区分へ移り、移動先の本文先頭とフォーカスが見える。先頭・末尾、長短の区分、狭い画面でリンクの方向と名前が正しい。JavaScript 無効時と全文表示でも通常のリンクとして移動でき、印刷では消える。初期 HTML と実表示の両方で確認する |
| 参照 | 非表示区分への直リンク、ページ内リンク、再読み込み、戻る・進むで目的の内容に到達する。閉じた `details` 内への参照は対象の祖先だけを開く |
| 検索 | 非表示区分にだけある語を実際のブラウザー内検索で探せる。未対応環境は全文表示で検索できる |
| ヘッダ・テーマ | ヘッダが本文と一緒にスクロールし、狭い画面・低い画面・拡大時も操作できる。操作名を読め、設定を保存できなくても切替が動く |
| タブの印刷 | 先頭以外のタブとダークモードから PDF を出し、全区分が一度ずつ含まれる。指定した補足だけが開き、画面用操作が消え、印刷後は元の状態へ戻る |

検索の試験は `beforematch` の手動発火だけで代用せず、未検証のブラウザーへ結果を一般化しない。

## 最後に通読する

ページを最初から読み、主題、節の関係、本文と補助要素の関係を自然に理解できるか確認する。

ラベルや説明の過不足は [説明とラベル](readability-and-layout.md#説明とラベル) の基準で見直す。

最後に [Skill 本文の「成果物の境界」](../SKILL.md#成果物の境界) を確認する。修正した場合は影響する箇所を再確認し、ページ全体をもう一度表示する。

検証は内容と実際の利用上の問題を確かめるために行う。装飾の値や実装そのものを固定するだけのテストは追加しない。残る具体的なリスクが解消したら、確認範囲を納品メッセージで伝える。
