## 基準となる表示

指定されたデザインがない場合は [document.css](../assets/document.css) を使い、[components.html](../assets/components.html) で部品の組み合わせを確認する。CSS を納品 HTML に含め、共通トークンで本文と部品を揃える。

- 背景、本文、見出し、強調、補助文字、境界、アクセント、リンクは用途別のトークンを使う
- 背景と本文は無彩色を基準にし、リンク・選択状態・図の要点へ控えめな一色を共用する。基準 CSS は青系のアクセントを使い、青み・暖かみの指定には同梱のパレットも使える
- 本文と見出しの階層は文字サイズと余白で表し、強調色はリンク、選択、意味のある区別に使う
- 個別の文書に必要なスタイルは基準 CSS の後へ追加し、同じ役割の部品には同じ設定を使う

明暗切替・印刷・タブの配置と操作条件は [ナビゲーションと文書操作](navigation-and-controls.md) を参照する。

## 文書の用途を確認する

ページの構成は、読者が主に何をするかに合わせる。

- 最初から順に読む
- 必要な箇所を探す
- 複数の項目を比較する
- 手順を実行する

一つのページに複数の用途があっても、読者の主な利用方法を決める。

## 文書構造

完全な HTML 文書として、少なくとも次を含める。

- `<!doctype html>`
- 本文の言語を示す `html[lang]`
- `meta charset`
- `meta name="viewport"`
- 内容を表す `title`
- 主要内容を含む一つの `main`
- 文書の主題を示す一つの `h1`

見出しは元資料の階層に対応させ、レベルを飛ばさない。配置を CSS で変える場合も、DOM だけで自然に読める順序を保つ。

## 本文とナビゲーション

一般的な長文は一列の本文を基準にする。ナビゲーションを加える場合も十分な本文幅を保ち、文字種、フォントサイズ、内容に合わせて実表示で調整する。

目次は節間の移動を助ける場合に付け、文言を見出しと合わせる。参照先には一意の ID を付ける。独立した区分の表示方式は [タブを選ぶ条件](navigation-and-controls.md#タブを選ぶ条件) を参照する。

## タイポグラフィと余白

- 本文を追いやすい文字サイズと行間を取る
- 見出しを、大きさだけでなく余白と階層で区別する
- 太字、斜体、色は強調箇所を読み分けられる範囲で使う
- 長い英数字、URL、コードを折返しや局所スクロールで読めるようにする

余白は内容のまとまりを示すために使い、枠線や背景はまとまりの区別を助ける場合に加える。

## 文書要素を HTML で表す

元資料の段落とリストの役割を保つ。連続した説明はつながりを保ち、独立した項目は用途に合う単位でまとめる。

項目間の対応や正確な値の参照には表を使い、行と列の関係を HTML で表す。

- `caption` または直前の見出しを参照する `aria-labelledby` で表の目的を示す。同じ題名を二重に表示しない
- `th` と `scope` で行列関係を示す

補足は控えめな罫線、追加説明は `details`、独立した対象や操作は必要に応じて区切った領域で示す。警告、注意、補足は、重要度に合う要素とラベルで示す。

コードは原資料の範囲を保ち、役割に応じて `code` または `pre` と `code` で表す。

## 数式

数式は KaTeX の HTML 出力に統一する。TeX / LaTeX に加え、MathML、Unicode、プレーンテキストによる式も、意味を保って KaTeX 対応の TeX へ整理する。出力設定、原式の保持、読み上げ名、未対応記法の扱いは [描画ライブラリ](renderers.md) に従う。

本文と数式の字面、行間、添字の読みやすさを実表示で合わせる。文書内では同じ設定を使い、`code`、`pre`、ユーザー入力例を数式の自動レンダリング対象から除く。単なる数値や単位は通常の本文で表す。

盤面の値など、本文から独立した数式では分数の分子・分母まで読める大きさを保つ。必要に応じて `\displaystyle` や式の領域の文字サイズを使い、括弧と上下の余白も確認する。本文中の式を一律に拡大しない。

## 可視化の選択

本文中の関係、変化、差を読み取れる表現を選ぶ。

推論を追いにくい箇所では、定義の対応や、計算・証明の途中で変わる対象を具体的に示す。描画ライブラリの選択と、図で説明する内容の設計を両方行う。

| 内容 | 表現 |
| --- | --- |
| 数量の比較・推移・分布 | 棒、点、線などのグラフ |
| 条件分岐・状態変化 | フローチャート、状態遷移図 |
| 依存関係・階層 | 関係図、木構造 |
| アルゴリズムの進行 | 同じ配置で段階を進める図 |
| 入力値による結果の変化 | 入力に連動する図 |

元資料の数値、条件、因果関係を保つ。新しい測定値や比較結果を作らない。説明用の例や仮定を加える場合はその位置づけを示し、実測と計算・仮定を区別する。正確な値を参照する用途には表を添える。

図の個数を目標にせず、読み取りや操作で分かることを基準に選ぶ。主要な内容は本文からも理解できるようにする。学習用の段階的な説明では、図や操作でも答えを開示する順序を保つ。

## 図と画像

図や画像は、内容との関係を保って配置する。

- 本文から図を参照する
- 図と説明を `figure` と `figcaption` でまとめる
- 代替テキストを図の目的に合わせる
- 装飾画像には空の `alt` を使う

図内の文字は本文と同じフォントを基本にする。フォントを部分収録する場合は、本文、コードの文字列・コメント、図、操作後のラベルまで対象にする。コードの英数字は等幅を保ち、そのフォントにない日本語などは本文用フォントでも補えるようにする。

グラフには軸、単位、必要な目盛りを付け、線や印の色は意味に対応させる。凡例の記号は SVG の図形や線、境界線、文字で表し、CSS の背景色だけに依存しない。背景を印刷しない設定でも、系列との対応を読めるようにする。

広い図を狭い画面へ縮小するだけで文字を小さくしない。配置の変更、目盛りや注記の整理、必要に応じた局所スクロールで読める大きさを保つ。SVG の文字サイズは CSS の指定値だけでなく、`viewBox` による縮小後の大きさで判断する。

## 配色とレスポンシブ表示

- 色を意味の唯一の手掛かりにしない
- 本文と背景のコントラストを確保する
- 基準 CSS の `color-scheme` と `light-dark()` で OS の明暗に追従する。独自 CSS では `prefers-color-scheme` も使える
- 数式、構文色、差分、図内のラベルと背景も同じ表示モードへ合わせる
- 広い画面、中間幅、狭い画面で内容を読めるようにする
- 表、コード、長い数式は、ページ全体ではなく各要素内で横スクロールさせる
- 固定要素で本文や操作対象を覆わない
- 文字拡大やズームで内容や操作を失わせない

基準 CSS のダークモードは暗い灰色の背景と落ち着いた明るさの本文を使い、見出しは少し明るく、短い強調は太さと文字色で区別する。本文中の数式とインラインコードは周囲の文字色に合わせる。

通常サイズの文字は実際の背景に対して少なくとも 4.5:1、基準 CSS の本文は 7:1 以上を保つ。コントラスト比は判読性の下限なので、背景を持つ注釈・表・コードも含めて、文字の多い画面で明るさを確認する。基準は [WCAG 2.2 の 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) と [1.4.6](https://www.w3.org/WAI/WCAG22/Understanding/contrast-enhanced.html) を参照する。

コードは文書と共通の背景面・基本文字色・アクセントを使う。構文、図の系列、差分の追加・削除など、意味の異なるものを見分けられる配色にする。

狭い画面でも全内容へ到達できる構造を保つ。印刷は白地に濃い文字を基本にし、コードと図を読める状態で残す。補足の開閉と全タブの扱いは [印刷](navigation-and-controls.md#印刷) を参照する。

コマンドと実行条件など、離れると意味を誤る短いまとまりは同じページへ保つ。長い節や大きな図を一括で改ページ禁止にして余白を増やさず、必要な箇所だけをまとめる。図は印刷用の配置を調整し、長い表は見出し行を繰り返して読めるようにする。

## 説明とラベル

見出し、名称、配置、選択状態で伝わることは、重複する説明を省ける。判断基準は、その文を消しても読者の理解・判断・操作・参照が変わらないかである。

本文の理由・条件・具体例、図表の単位・凡例・出典、操作名は必要に応じて保つ。特定のラベルやレイアウト形式を一律に避けず、読者に役立つかで選ぶ。意味が伝わりにくいアイコンには短い可視ラベルを付ける。

## 操作機能

標準 HTML で実現できる操作を優先し、JavaScript を使う場合も主要な内容を初期 HTML に含める。

ラベル付きの `button`、`input`、`select` を使い、現在値や選択状態を表示する。キーボードで操作でき、ホバーに依存せず読めるようにする。動的な結果には必要に応じて `output` や `aria-live="polite"` を使う。動きを付ける場合は `prefers-reduced-motion` に従う。

テーマと印刷は [アイコンボタン](navigation-and-controls.md#ヘッダとアイコンボタン) の基準に従う。視覚上の重複を減らしても、支援技術へ伝える名前や状態を削除しない。

JavaScript に依存する操作欄は初期状態で `hidden` にし、初期化できた後に表示する。ネイティブ HTML の操作はそのまま使う。図の探索が主目的の文書では、操作できない場合に確認できる値や説明を用意する。
