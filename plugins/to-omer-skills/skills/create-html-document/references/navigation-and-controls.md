## タブを選ぶ条件

文字数ではなく、読者がどの内容を一緒に読むかで決める。

| 読み方 | 基本の構成 |
| --- | --- |
| 定義から導出・証明・例へ順に進む | 一列の本文と必要な目次 |
| 条件や候補を見比べる | 並べた説明または比較表 |
| 必要な仕様・事例・資料群を独立して参照する | 少数の大分類のタブと全文表示 |
| 一時的に詳細やヒントを確認する | 必要箇所だけの `details` |

分類名は中身が分かる短い語にし、必要な前提は共通の導入または該当箇所で読めるようにする。区分が増えて選びにくい場合は、分類か表示方式を見直す。

## 全文表示と内容の保持

全区分を元の順序で初期 HTML に含め、一つの本文を表示切替で扱う。JavaScript の初期化前は全区分を表示し、分類リンクを通常のページ内リンクにする。JavaScript に依存するボタンは初期化後に表示する。

タブ列の近くに、内容分類とは別の「全文表示」切替を置く。全文表示中は全区分を連続して読み、分類リンクを目次として使えるようにする。この状態ではタブの役割・選択状態を外す。

## 移動とキーボード

タブ表示では WAI-ARIA APG のタブパターンに合わせる。

- タブ列に `role="tablist"` と名前を付け、各タブに `role="tab"`、`aria-controls`、`aria-selected` を付ける
- 各パネルに `role="tabpanel"` と `aria-labelledby` を付ける。先頭内容へフォーカスできない場合はパネルを `tabindex="0"` にする
- 選択タブだけを通常の Tab 移動に含める。共通部品は左右キー・Home・End でフォーカスを移し、Enter・Space で選択を確定する
- 横向きのタブ列では上下キーを奪わず、通常のスクロールを保つ。選択表示とフォーカスを色だけに頼らず区別する

区分とその内部の見出しへ安定した ID を付ける。URL のフラグメント、ページ内リンク、再読み込み、戻る・進むから対象区分を表示する。閉じた `details` 内への明示的な移動では、対象の祖先だけを開いてからフォーカス・スクロールする。履歴は確定した移動単位で残し、タブ列での切替ではページの位置と入力値を保つ。

狭い画面でもラベルを読める大きさで保つ。横スクロールが必要ならタブ列の内部に限定し、選択したタブを見える位置へ出す。

各パネルの末尾に、隣の区分へ移る通常のページ内リンクを初期 HTML として含める。タブの順序と名前から `href` と表示名を決め、JavaScript による生成だけに依存しない。共通 JavaScript のページ内リンク処理で移動する。

- 左に「← 前の区分名」、右に「次の区分名 →」を表示し、存在しない側は省く。短い本文でも直後に置き、長い区分名は折り返す
- タブ表示での移動時は表示パネル・選択タブ・URL を同期し、移動先の本文先頭へスクロールとフォーカスを移す。入力値は保つ
- 通常フローに置き、全文表示や JavaScript 無効時も章間のリンクとして使えるようにする。印刷時は隠す。前後リンクにはタブの役割や左右キー操作を付けない

静的リンクの読み上げ名も文書の言語で記述する。

## 検索と互換性

共通部品は `hidden="until-found"` と `beforematch` で、ブラウザー内検索の対象パネルとタブの選択を同期する。通常の `hidden` / `display: none` では非表示本文が検索対象にならないため、`until-found` を `display: none` で上書きしない。隠れたパネルの余白・枠・背景も取り除く。

機能検出で対応を確認できない環境は全文表示から始め、ブラウザー標準の検索を使う。対応環境でも実際の検索動作を確認する。この仕組みの対象はタブで隠した区分とし、未開示の解答など別の目的で閉じた内容はその状態を保つ。

## ヘッダとアイコンボタン

通常は、短い題名と明暗切替・印刷のアイコンを冒頭の低いヘッダへまとめる。ヘッダとタブ列は本文と一緒にスクロールする通常フローに置く。ページ内リンクの移動先には少量の余白を確保する。固定・追従表示の指定がある場合は、本文とキーボードフォーカスを覆わないように調整する。

アイコンボタンは次を満たす。

- ネイティブ `button type="button"` を使い、`aria-label` または視覚的に隠したテキストで短い操作名を付ける。SVG は装飾として扱う
- ホバーとキーボードフォーカスで操作名を確認できるようにする。`title` 属性だけに依存しない
- 操作領域は 44 CSS px 程度を目安にし、フォーカスを見える状態にする
- 「全文表示」などアイコンだけでは分かりにくい操作には短い可視ラベルを残す

テーマの初期値は OS の明暗設定に合わせ、読者の手動選択を優先する。選択を保存できなくても切替や他の機能は動かす。

共通部品はテーマボタンに次の操作名を表示する。`data-theme-label-light` と `data-theme-label-dark` に、それぞれのモードへ切り替える操作名を文書の言語で指定する。名前は `aria-label` とツールチップへ反映されるため、`aria-pressed` は併用しない。

## 印刷

表示中のタブに関係なく、文書の全区分を元の順序で一度ずつ印刷する。操作ヘッダ、タブ列、全文表示の切替など画面用操作は印刷しない。

`@media print` でタブの非表示指定と高さ制限を解除し、白地に濃い文字で出す。ブラウザーの印刷メニューからも同じ内容を出せるようにする。

補足の展開は `details[data-print="open"]` に限定し、未開示の解答は閉じた状態を保つ。`beforeprint` / `afterprint` を使う場合は、印刷後に画面の選択タブ・テーマ・開閉状態を戻す。改ページを含む確認は [検証手順](validation.md) を参照する。

## 部品の組み込み

[components.html](../assets/components.html) は連続表示、[tabbed-document.html](../assets/tabbed-document.html) は独立区分を切り替える文書の見本である。[document.css](../assets/document.css) と [document.js](../assets/document.js) を合わせて使う。

見本の文章、題名、区分数、識別子を文書に合わせて置き換える。採用した部品の CSS・JavaScript・アイコンを納品 HTML へインライン化する。
