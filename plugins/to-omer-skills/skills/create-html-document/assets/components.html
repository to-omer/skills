調査記録

調査記録を一つにまとめる

集めた情報を、出典と判断の関係が分かる形で残す。後から読む人が、確認済みの事実と、これから確かめることを追えるようにする。

記録する項目

一つの記録には、確認した内容、出典、確認日をまとめる。複数の出典が同じ事実を扱う場合は、対応を保ったまま関連付ける。

  1. 何を確認したいかを一文で書く
  2. 判断に必要な原資料を読む
  3. 確認できたことと、未解決の点を分けて記す

情報の位置づけを残す。 計算結果や説明用の仮定は、その条件とともに記録する。

出典が更新されたとき

変更した記述とその根拠を確認し、以前の判断に影響する箇所を更新する。関連する記録も、元の出典へ戻って確かめる。

確認の進み具合

記録の状態を同じ分類で集計すると、次に読む資料を選びやすくなる。下の値は、表示を説明するための例である。

同じ形式で保存する

記録の識別子は更新後も保つ。たとえば、確認状態は status に格納できる。
