# 推敲の例

- 以下は、表現を直す範囲を示す作例である。
  - 実在の製品、規約、調査結果ではない。
  - 添えた資料や文脈から分かる意味だけを使う。
  - 例の形式を、すべての文書へ当てはめない。

## 階層を保って、不自然な語の組み合わせを直す

**推敲前**

```markdown
- 定期集計には、A案の採用を行う。
  - 担当者の不在時にも、集計の実行を可能とする。
  - 費用は、予算の範囲に所在する。
```

**推敲後**

```markdown
- 定期集計には、A案を採用する。
  - 担当者が不在でも、集計できる。
  - 費用は予算内に収まる。
```

- 語彙と述語を直し、結論と理由の分け方は保った。
  - 自然な日本語にするために、一つの段落へ戻す必要はない。

## 自然な短文や、同じ語尾を無理に変えない

**原稿**

```markdown
- 受付は17時までです。
  - 土日も同じ時間です。
- 受取は窓口のみです。
```

**推敲後**

```markdown
- 受付は17時までです。
  - 土日も同じ時間です。
- 受取は窓口のみです。
```

- 意味が明確で、文末にも問題がないため変更しない。
  - 「です」が続くことだけを理由に、項目をつなげない。

## ラベルを、長い説明文へ変えない

**推敲前**

```markdown
- 申込期限について：金曜17時
- 必要となる書類：申込書
```

**推敲後**

```markdown
- 申込期限：金曜17時
- 必要書類：申込書
```

- ラベルとして意味が通じるため、不要な語だけを省いた。
  - 「申込期限は金曜17時です」と書き換えることを必須にしない。
  - 同じ扱いは、表の見出しやセルの短い文言にも当てはまる。

## 報告と予定を、語尾の変化で取り違えない

**文脈**

> 書き手自身が完了した変更を報告する。受付時間を延長した。申込方法は変更していない。

**推敲前**

> 受付時間の延長を実施しました。申込方法の変更は実施していません。

**推敲後**

> 受付時間を延長しました。申込方法は変更していません。

- 完了した変更と、変更していないことを区別したまま短くした。
  - 「受付時間を延長します」という予定には変えない。
  - 地の文として読めるため、箇条書きへ変える必要もない。

## 途中稿に抜けた限定を、資料に照らして戻す

**元の資料**

> 架空の試験では、12人の自己評価の平均が2.8から3.6になった。個人別の変化は不明である。

**推敲前の途中稿**

```markdown
- 架空の試験で、12人の自己評価が上がった。
  - 平均は2.8から3.6になった。
- 個人別の変化は不明である。
```

**推敲後**

```markdown
- 架空の試験で、12人の自己評価の平均が上がった。
  - 平均は2.8から3.6になった。
- 個人別の変化は不明である。
```

- 資料が示すのは平均の変化なので、親項目にも「平均」を戻した。
  - 階層を残すことを理由に、途中稿の限定不足まで保たない。
  - 新しい理由や、個人別の結果は加えていない。

## 共通条件を残して、言い回しだけを短くする

**元の資料**

> 架空の点検手順では、検査で異常がなければ、ふたを閉じて運転を再開する。

**推敲前**

```markdown
1. 検査で異常がない場合に限り、ふたを閉じる操作を行い、運転の再開を行う。
```

**推敲後**

```markdown
1. 検査で異常がなければ、ふたを閉じて運転を再開する。
```

- 共通の条件が掛かる短い二操作を、一項目に残した。
  - 「異常がなければ、ふたを閉じる」「運転を再開する」と分け、後半を無条件にしない。

## 主体が不明なら、担当者を作らない

**原稿**

> 確認を行った後に、登録内容の更新を行います。

**推敲後**

> 確認後に、登録内容を更新します。

- 原文だけでは、誰が確認し、誰が更新するかは分からない。
  - この推敲でも、主体を明確にできたわけではない。
  - 「担当者が確認し、利用者が更新する」とは補わない。
  - 主体の特定が必要なら、確認事項として本文と分けて伝える。

## 数式は保ち、その周りの日本語を直す

式変形の説明だけを示す。

**推敲前**

```markdown
- $2 = \frac{a^2}{b^2}$ の両辺に対して $b^2$ の乗算を実施する。
  - その結果として、$a^2 = 2b^2$ の獲得が可能となる。
```

**推敲後**

```markdown
- $2 = \frac{a^2}{b^2}$ の両辺に $b^2$ を掛ける。
  - $a^2 = 2b^2$ が得られる。
```

- 式、操作、親子項目を保ち、日本語だけを直した。
  - 数式を通常の文章やコード表記へ置き換えない。
  - コードや引用を含む文章でも、変更の対象と引用などの内部を区別する。
