# 根拠と適用範囲

読みやすさ、自然な日本語、文書構造、アクセシビリティに関する規則の根拠と、適用上の注意を示す。

## 日本語の公的な指針

### 文化審議会建議「公用文作成の考え方」

https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/hokoku/pdf/93650001_01.pdf

次の観点を重視する。

- 読み手に応じた情報の選択と構成
- 主述、修飾、文の長さ、用語、表記
- 義務、依頼、説明など目的に応じた書き分け

### 在留支援のためのやさしい日本語ガイドライン

https://www.moj.go.jp/isa/support/portal/plainjapanese_guideline.html

次の観点を重視する。

- 読者の背景知識を想定する
- 一文の構造と主体を明確にする
- 必要に応じて具体的な日付、数値、語の説明を使う

やさしい日本語の規則は、対象読者と目的に応じて適用し、すべての文書へ一律に適用しない。

## プレーンランゲージ

### ISO 24495-1:2023 Plain language — Part 1

https://www.iso.org/standard/78907.html

次の四点を基準にする。

- 読者が必要な情報を得られる
- 必要な情報を見つけられる
- 内容を理解できる
- 情報を利用できる

これらに加え、概念の依存順序、段落の流れ、説明の濃淡も確認する。

## Web の構造とアクセシビリティ

### Web Content Accessibility Guidelines 2.2

https://www.w3.org/TR/WCAG22/

### W3C WAI Tutorials

https://www.w3.org/WAI/tutorials/

見出し、リスト、表、画像代替、色以外の手掛かり、意味上の読み順を確認する。HTML の実装では `create-html-document` Skill も適用する。

## Markdown と HTML

### CommonMark

https://spec.commonmark.org/

### GitHub Flavored Markdown

https://github.github.com/gfm/

### WHATWG HTML Living Standard

https://html.spec.whatwg.org/

構文は、見た目ではなく意味上の役割に対応させる。

## 読解と文章構造

### Lorch, R. F. Jr. (1989), Text-signaling devices and their effects on reading and memory processes

見出しや予告などの信号は、文書構造の把握を助ける。ただし、数を増やすこと自体を目的にしない。

### McNamara, D. S. et al. (1996), Are good texts always better?

読者の背景知識に応じて、必要な前提を明示する。補足を無制限に増やさない。

## 限界

この Skill は、事実確認、法的・医療的な妥当性、読者調査、アクセシビリティ監査を自動的に保証しない。利用可能な根拠やツールを使い、実施していない確認を実施済みと扱わない。
