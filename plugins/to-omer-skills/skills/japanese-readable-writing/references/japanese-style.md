# 自然な日本語

文、語句、助詞、条件、否定、用語、表記、句読点を、意味を保ちながら自然な日本語へ整える。

## 基本方針

文法的に成立するだけでなく、読者が文を読み終えた後に構造を組み直さなくてよい日本語にする。

確認の中心は次の四点である。

- 誰が、何を、どうするかが分かる
- 修飾語、条件、否定のかかる範囲が一つに定まる
- 語の組み合わせと語順が日本語として自然である
- 文が続いたときに、同じ構文や文末が機械的に反復しない

## 主体、行為、対象

主体を毎文で明示する必要はない。ただし、省略によって複数の主体が考えられる場合は補う。

悪い例:

> 申請後に確認し、必要なら修正します。

誰が確認し、誰が修正するか分からない。

改善例:

> 担当者が申請内容を確認します。不備がある場合は、申請者が修正します。

## 主語と述語

長い修飾句を挟むと、主語と述語の対応が崩れやすい。主語と述語を近づけるか、文を分ける。

悪い例:

> この変更は、利用者から寄せられた要望と、昨年実施した調査で確認された課題を踏まえ、今後の利用増加にも対応するため、実施します。

改善例:

> 利用者の要望と昨年の調査結果を踏まえ、この変更を実施します。今後の利用増加へ対応することも目的です。

## 動詞と目的語

日本語で自然に結び付く組み合わせを使う。英語の動詞を一つの日本語へ固定して当てはめない。

- `設定の変更を行う` → `設定を変更する`
- `影響を経験する` → `影響を受ける`
- `順序を崩す` → `順序を前後させる`
- `強さを壊す` → `義務や推奨の度合いを変える`
- `判断を実行する` → `判断する` または `判断に基づいて実行する`

## 助詞

助詞を省きすぎると、名詞同士の関係が曖昧になる。

- `意味保存` → `意味の保存`
- `利用者確認` → 文脈に応じて `利用者の確認`、`利用者を確認すること`、`利用者による確認`
- `設定変更対象` → `設定を変更する対象`

`は` と `が`、`に` と `へ`、`を` と `について` は、焦点と関係が変わるため機械的に置き換えない。

## 名詞の連続と名詞化

名詞が続く場合は、助詞や動詞を補う。

悪い例:

> 利用状況確認結果共有方法変更

改善例:

> 利用状況の確認結果を共有する方法の変更

さらに自然にするなら、文へ戻す。

> 利用状況を確認した結果の共有方法を変更します。

動作を示す場合は、`実施する`、`行う`、`実現する` を足すより、具体的な動詞を使う。

## 修飾語

修飾語は修飾先の近くへ置く。複数の解釈が可能な文を、根拠なく一つへ決めない。

曖昧な例:

> 新しい利用者の登録方法を説明します。

考えられる意味:

- 新しい利用者を登録する方法
- 新しく変更された登録方法

原文だけで決められない場合は、確認するか、曖昧さを保つ。

## 一文の情報量

「一文一義」は、一文へ情報を一つしか置かないという意味ではない。理由、条件、対比が密接なら、一文で結んだ方が分かりやすい。

悪い例:

> 通知は非同期です。失敗することがあります。古い値が返ります。

改善例:

> 通知は非同期であるため、失敗すると古い値が返ることがあります。

ただし、条件が重なり、主述関係を追いにくくなったら分ける。

## 文の長さとリズム

文字数だけで長文を判定しない。次の兆候がある文は分割を検討する。

- 主語と述語が遠い
- 条件や括弧が重なる
- 一つの文に複数の論点が入る
- 読み終えないと冒頭の意味を確定できない

短文が連続すると、因果関係が切れ、単調になる。文の長さと文末には、内容に応じた変化を付ける。

## 条件と例外

条件は、何にかかるかが分かる位置へ置く。

悪い例:

> 申請できます。管理者の承認がある場合に限ります。外部利用者は対象外です。

改善例:

> 管理者の承認がある場合に限り申請できます。ただし、外部利用者は対象外です。

複数の条件が組み合わさる場合は、地の文だけで無理に表さず、判断表を検討する。

## 否定

否定する範囲を明確にする。

曖昧な例:

> すべての利用者が申請する必要はありません。

考えられる意味:

- 誰も申請する必要がない
- 一部の利用者だけ申請すればよい

意図に応じて書き分ける。

> 利用者は申請する必要がありません。

> 一部の利用者だけが申請してください。

## 義務、推奨、予定、推測

強さを変えない。

| 意味 | 代表的な表現 |
|---|---|
| 義務 | しなければならない、必須である |
| 禁止 | してはならない、禁止する |
| 推奨 | することを推奨する、望ましい |
| 許可 | してよい、可能である |
| 予定 | する予定である、見込みである |
| 推測 | と考えられる、可能性がある |
| 未確認 | 未確認である、要確認である |

`できます` は、能力、許可、可能性のいずれにも読める。必要なら意味を具体化する。

## 指示語

`これ`、`それ`、`前述の内容` などの参照先が複数ある場合は、対象を言い直す。近い範囲で参照先が一つに定まる場合は、同じ名詞を過剰に繰り返さなくてよい。

## 接続表現

接続詞は関係に合わせる。

- 因果: `そのため`、`したがって`
- 対比: `一方`、`これに対して`
- 例外: `ただし`
- 追加: `また`、`さらに`
- 具体化: `例えば`
- 言い換え: `つまり`

`なお` を、関係の異なる情報を無理に接続するために使わない。接続詞が多い場合は、順序や段落構成を見直す。

## 用語

同じ概念には同じ語を使う。似た語を文体上の変化だけを目的に入れ替えない。

専門語は、正確さを失う平易語へ置き換えない。読者が知らない可能性がある場合は、初出で短く説明する。

略語は、読者に既知でなければ初出で正式名称を示す。外来語は、定着した語まで不自然な和語へ置き換えない。

## 抽象的な評価語

`重要`、`適切`、`十分`、`迅速`、`効果的` などは、必要に応じて基準や理由を添える。

悪い例:

> 適切に処理してください。

改善例:

> 受信から24時間以内に担当者を割り当ててください。

基準が分からない場合は、具体化したふりをせず、確認事項として残す。

## 直訳調

次のような表現は、意味を確かめて自然な日本語へ直す。

- `〜を可能にする` の連続
- `〜を提供する` の過剰使用
- 無生物主語が人の判断や行為を行う文
- 抽象名詞を主語とする長い文
- 英語の修飾順を保った名詞列
- `単なるAではなくB`、`多角的に`、`包括的に` など、中身の代わりになった定型句

悪い例:

> この機能は、利用者が迅速な意思決定を行うことを可能にします。

改善例:

> この機能を使うと、利用者は必要な情報を早く比較できます。

## 書き手の声

読みやすくするために、すべての文章を同じ無個性な文体へ変えない。会話的な文章、エッセイ、紹介文では、書き手の語り口やリズムに意味がある。

ただし、声を残すことを理由に、曖昧さ、冗長さ、誤解を招く表現を放置しない。

## 丁寧さ

丁寧な前置きが要点を隠す場合は短くする。

悪い例:

> 大変お手数をおかけすることとなり誠に恐縮ではございますが、以下の内容についてご確認いただけますと幸いです。

改善例:

> お手数ですが、以下の内容をご確認ください。

関係性や場面に必要な敬意は保つ。

## 日付、数値、単位

曖昧な相対表現が誤解を招く場合は、具体的にする。

- `来週` → 必要なら具体的な日付
- `しばらく` → 分かる範囲の期間
- `多い` → 比較対象や数値

数値、単位、範囲、丸め方を勝手に変えない。全角・半角や桁区切りは、用途と既存の表記に合わせる。

## 句読点と括弧

読点は、係り受け、並列、条件の境界を明確にするために使う。一定文字数ごとに機械的に置かない。

括弧が重なる場合は、文へ戻すか、注記を分ける。括弧内へ重要な条件を隠さない。

### 箇条書きの句点

完全な文には句点を付ける。見出し、ラベル、名詞句、短い並列項目には原則として句点を付けない。

例:

```markdown
保持する情報

- 事実、数値、日時、単位
- 条件、例外、否定
- 専門語と固有名
```

```markdown
確認事項

- 条件や例外を削らない。
- 未確認事項は、未確認であると明記する。
- 原文にない因果関係を加えない。
```

一つのリストで文と句が混在する場合は、句点だけをそろえず、項目の文法形式を見直す。

## 表記

文書内で次をそろえる。

- 漢字と仮名の選択
- 数字の全角・半角
- 日付と時刻の形式
- 外来語の長音
- 製品名、機能名、固有名の表記
- 括弧、引用符、記号

表記統一のために、引用、コード、正式名称まで書き換えない。

## やさしい日本語

やさしい日本語が求められた場合は、短い文、身近な語、明確な主体、具体的な日時、読み仮名などを検討する。ただし、専門的な意味や義務の強さを弱めない。

## 最後に通して読む

一文ずつ正しくても、段落として不自然なことがある。最後に声に出すか、それに近い速度で通読し、次を確認する。

- 同じ文末や構文が続いていないか
- 一文目から二文目へ自然に進めるか
- 指示語の参照先を保持し続けなくてよいか
- 抽象的な説明が長く続いていないか
- 重要な文が、周囲の定型句に埋もれていないか
