# 自然な日本語

文法的に誤りがないだけでなく、読者が主語、述語、修飾先、条件、文同士の関係を読み直さずに理解できる日本語にする。

## 主体、主語、述語を対応させる

主語を省いても自然な場合は省ける。ただし、主体が切り替わる箇所、複数の候補がある箇所、責任や判断の所在が重要な箇所では明示する。

> 申請後に確認し、必要なら修正します。

この文では、確認する人と修正する人が分からない。主体が異なるなら、次のように書き分ける。

> 担当者が申請内容を確認します。不備がある場合は、申請者が修正します。

主語と述語が意味の上でも文法の上でも対応しているかを見る。長い修飾部によって対応が崩れる場合は、主語と述語を近づけるか、文を分ける。

「これ」「それ」「同様に」「前者」などは、指示先が一つに定まる場合だけ使う。候補が複数ある場合は具体名を繰り返す。

## 修飾関係と並列を明確にする

修飾語を修飾先の近くに置く。長い修飾部は文の前半に詰め込まず、文を分けるか、先に前提として説明する。

> 新しい利用者の登録方法

この表現は「新しい利用者を登録する方法」と「新しく変更された登録方法」の両方に読める。原文から決められない場合は、勝手に一方へ確定しない。

並列する語句は、文法上の形と意味の詳しさをそろえる。名詞、動詞、文を同じ階層で混在させない。

## 動詞、目的語、助詞を整える

動詞と目的語が日本語として自然に結び付くかを見る。抽象名詞に「行う」「実施する」「実現する」を足すより、意味に合う動詞を使う。

- `設定の変更を行う` → `設定を変更する`
- `影響を経験する` → `影響を受ける`
- `判断を実行する` → `判断する` または `判断に基づいて実行する`

助詞を省いて名詞を連ねると、語同士の関係が曖昧になる。助詞を補うか、文へ戻す。

- `利用者確認` → 文脈に応じて `利用者の確認`、`利用者を確認すること`、`利用者による確認`
- `利用状況確認結果共有方法` → `利用状況を確認した結果の共有方法`

`は` と `が`、`に` と `へ`、`を` と `について` は、焦点や関係が変わるため機械的に置き換えない。

## 条件、否定、確信度を保つ

条件と結論を近づけ、どの条件がどの文にかかるかを明確にする。例外や除外を括弧内へ追いやらない。

否定は、否定する語句の近くに置く。「すべての利用者が申請する必要はない」のように複数の意味に読める文は、「誰も申請する必要はない」「一部の利用者だけが申請する」のように意図を明示する。

二重否定や「〜とは限らない」を、強い肯定や全面否定へ変えない。義務、禁止、推奨、許可、予定、可能性、推測も、読みやすさのために同じ強さへそろえない。

## 一文の情報量とつながりを整える

主語、目的、条件、例外、補足が重なり、文末まで関係が確定しない文は分ける。一方、短い文へ機械的に分割して、因果や対比を見えにくくしない。

文の長さではなく、読み終えたときに構造を組み直す必要があるかで判断する。分割後は、前後の関係を語順または適切な接続表現で示す。

接続詞は、因果、対比、例外、追加、具体化など、実際の関係に合わせる。「なお」や「また」で関係のない内容をつながない。接続詞が多い場合は、文や段落の順序を見直す。

## 用語と抽象表現を整える

同じ概念には同じ語を使い、別の概念を同じ語で呼ばない。専門用語や略語は、想定読者が知らないと本文を理解できない場合に、最初の使用箇所で説明する。

「重要」「適切」「十分」「迅速」「効果的」など、基準の分からない評価語だけで指示や説明を終えない。基準を確認できない場合は、具体化したふりをしない。

原文の語順や抽象名詞を残した直訳調、無生物が人の判断や行為をする不自然な文、内容のない定型句を避ける。直訳調かどうかは、原語との対応ではなく、日本語だけを読んで自然に意味が伝わるかで判断する。

英語の用語を日本語で表す場合は、定着した訳語またはカタカナ表記を使う。漢字へ機械的に置き換えた語や、一般的でない複合語を作らない。専門分野で使われる語でも、一般向けの文書で意味が伝わりにくい場合は、文脈に合う日本語で説明する。

タイトル、見出し、ラベル、中心用語に使う訳語や、自分で組み立てた複合語は、対象分野と読者に合う日本語用例で確かめる。定着した用例を確認できなければ新しい訳語を作らず、意味を説明する普通の言葉に置き換える。

- `情報への可視性を提供する` → `情報を見つけやすくする`
- `意思決定を行うことを可能にする` → 文脈に応じて `判断できるようにする` または具体的な行為を書く

## 文体と読者に合わせる

敬体と常体、用語、送り仮名、数字や記号の表し方を文書内でそろえる。ただし、引用、コード、固有名、意図的な語り口は維持する。

過度な前置き、定型的な丁寧表現、書き手の自己評価は、内容の理解に役立たなければ削る。書き手らしい語り口まで無機質な文体へそろえない。

平易な表現を必要とする読者には、一文を短めにし、具体的な語を使い、手順を順番に示す。漢字を減らすだけでなく、前提知識と情報量も調整する。専門家向けの文書では、正確な専門語を曖昧な日常語へ置き換えない。

## 数字、句読点、表記を整える

日付、時刻、期間、単位は、誤読しにくい書式で統一する。相対日付が誤解を招く場合は年月日を示す。数値、単位、範囲、丸め方は勝手に変えない。

読点は、係り受け、並列、条件の境界を明確にするために使い、一定の文字数ごとに置かない。括弧や引用符は対応させ、重要な条件を括弧内へ隠さない。

完全な文には句点を付ける。見出し、ラベル、名詞句、短い並列項目には付けない。リスト内で句と文が混在する場合は、文法上の形をそろえる。

漢字と仮名、全角と半角、日付と時刻、外来語、固有名、括弧や記号の表し方を文書内でそろえる。表記統一のために、引用、コード、正式名称まで書き換えない。
