# 日本語の表現

- 文法だけでなく、文脈に合う語と自然な言い回しを選ぶ。
  - 意味と構成の扱いは、[基本方針](../SKILL.md)に従う。
  - 文を長くすることも、語句を省くことも、それ自体を目標にしない。

## 主体、主語、述語を対応させる

- 誰が何をするのかが分かる文にする。
  - 主語を省いても明確なら、無理に補わない。
  - 主体が変わる箇所や、候補が複数ある箇所では明示する。
  - 補うのは、原文や資料から分かる主体と対象だけにする。
- 主語と述語が、意味の上でも対応しているか確かめる。
  - 修飾部分が長い場合は、語順を整えるか文を分ける。
  - 操作する人と、システムの動作を混同しない。
- 指示語は、読者が指す内容を特定できるときに使う。
  - 「これ」「そのため」「前者」などの参照先を確かめる。
  - 候補が複数ある場合や、離れた項目を指す場合は具体名で書く。
  - 親項目から対象が分かる子項目に、同じ主語を毎回足さない。

## 修飾語と助詞を整える

- 修飾語は、修飾する語の近くに置く。
  - 語順を変えても、条件や否定が掛かる範囲を保つ。
  - 複数の意味に読める表現は、文脈で確定できる範囲だけ直す。
- 助詞を省いて、関係の分からない名詞を並べない。
  - 「利用者確認」は、誰が誰を確認するのかに応じて書き分ける。
  - 「利用者が確認する」と「利用者を確認する」を取り違えない。
  - 短いラベルでも意味が明確なら、無理に文へ変えない。
- 「は」と「が」、「を」と「について」などを機械的に置き換えない。
  - 話題や焦点、動作の対象が変わらないか確かめる。
- 同じ役割で並ぶ語句は、文法上の形をそろえる。
  - 見出しと説明文など、役割が異なるものまでそろえない。
  - 項目をそろえるために、事実や説明を追加しない。

## 語彙と動詞の組み合わせを見直す

- 文脈に合い、意味を取り違えにくい語を選ぶ。
  - 「目的に働く情報」は「目的の達成に役立つ情報」とする。
  - 「設定の変更を行う」は「設定を変更する」とする。
  - 抽象的な名詞に「行う」「実施する」を添えただけの表現は見直す。
- 名詞だけでなく、動詞や修飾語との組み合わせも確かめる。
  - 「影響を経験する」は、文脈に合えば「影響を受ける」とする。
  - 一語ずつの置換で、不自然な係り受けを残さない。
- 意味の広い語を、根拠なく狭い語へ置き換えない。
  - 「使うには月300ドルかかる」という文だけでは、費用の内訳は分からない。
  - 費用の内訳が不明なら、「使うには月300ドルかかる」などとする。
- 同じ概念には同じ語を使い、違う概念を同じ語で呼ばない。
  - 語句を繰り返さないためだけに、別の専門語へ言い換えない。
- 専門語は、読者と分野に合う表現を保つ。
  - 定着した用語を、曖昧な日常語や独自の訳語へ変えない。
  - 訳語が不確かなら、用例を確認できる一次資料に当たる。
  - 対象が分からないまま、もっともらしい専門語を当てはめない。
- 読者に必要な用語の説明は、資料にある意味の範囲で整える。
  - 正確さを保って短く説明できるなら、その場で言い換える。
  - 曖昧な評価語は、資料から基準が分かる場合に具体的に言い換える。
  - 不明な定義や、評価語の基準を作って補わない。

## 条件、否定、確信度を保つ

- 条件と結論の関係が、言葉でも分かるようにする。
  - 文を分けたりつないだりした後は、条件の掛かる範囲を確かめる。
  - 共通条件のある操作を分けるときは、後の操作も条件付きだと分かる形にする。
- 数量や対象を限定する語を落とさない。
  - 「平均」「一部」「両方」「いずれか」「だけ」などを確認する。
  - 平均値の変化を全員の変化へ、特定の方法への否定を全体への否定へ変えない。
- 否定が曖昧な場合は、原文や資料を確かめてから言い換える。
  - 「全員が申請する必要はない」は、誰に申請義務があるかを確定してから直す。
  - 一部の人に義務がないことと、誰にも義務がないことを区別する。
- 断定、推測、可能性の強さを保つ。
  - 「とは限らない」を肯定や全面否定へ変えない。
  - 「推奨」を「必須」へ、「できます」を「します」へ変えない。
- 「ただし」「一方で」「〜ではなく」などの関係を保つ。
  - 否定や対比に意味があれば、肯定文へ一律に直さない。
  - 短くするために、異論や留保を削らない。

## 文同士のつながりを整える

- 接続表現は、実際の関係に合わせる。
  - 理由、対比、例外、追加、具体化を区別する。
  - 「そのため」を足して、元にない因果関係を作らない。
- 短い文でも関係が伝わるなら、つながずに残す。
  - 箇条書きでも、親項目との関係や前後のつながりを読む。
  - 同じ対象を指すために必要な繰り返しは、省略しない。
- 文を分ける場合は、後の文だけが無条件の断定にならないか確かめる。
  - 主体、時点、対象の切り替わりも明示する。
- 意味を変えない冗長な言い回しは短くする。
  - 読み飛ばした項目を補う再掲や、語りに必要な反復とは区別する。
  - 文体を整えるために、説明や根拠そのものを削らない。

## 文末と語り口を整える

- 文末は、誰のどのような発言なのかに合わせる。
  - 事実の説明、実施済みの報告、今後の予定、依頼、決まりを区別する。
  - 完了した変更を予定の「〜します」へ、決まりを助言の「〜しましょう」へ変えない。
  - 文書の種類だけを理由に、すべての文を同じ働きへそろえない。
- 敬体と常体は、指定がなければ原文を保つ。
  - 意図のない混在を直し、引用や語り分けは保つ。
  - 同じ語尾が続いても自然なら、無理に変えない。
- 短い見出しやラベルは、その役割に合う形にする。
  - 「申込期限」「対象者」などに「です」を機械的に足さない。
  - 操作の指示や条件の説明まで、名詞だけに切り詰めない。
- 直訳調や不自然な比喩は、文脈に合う日本語へ直す。
  - 意図された専門表現、皮肉、ためらい、慣用句は保つ。
  - 道具の動作を説明する自然な文まで、擬人化とみなして直さない。
- 前置きや丁寧表現は、必要な意味を残して整える。
  - 筆者の評価や異論を、内容のない装飾と取り違えない。
  - 批判の強さや筆者らしい語り口を、穏当な表現へ一律にそろえない。

## 表記と記法を保つ

- 数字、日付、単位、送り仮名などは、文書内でそろえる。
  - 値、単位、範囲、丸め方は変えない。
  - 相対日付を年月日にするのは、基準の日が分かる場合に限る。
  - 引用、正式名称、識別子まで表記統一の対象にしない。
- 読点は、係り受けや条件の区切りが分かる位置に置く。
  - 一定の文字数ごとに打たない。
- 句点の有無は、原稿や指定、併用時に採用した表記方針に合わせる。
  - 句点を省く方針なら、文として書く項目にも付け直さない。
  - 表記方針がない場合は、文として書く項目に句点を付ける。
  - 同じ役割の項目では、句点の有無をそろえる。
- 見出し、ラベル、表の文言は、対応する本文や値と照合する。
  - 言い換えても、対象、期限、条件、単位が分かる形を保つ。
  - 同じ単語を使うだけでなく、同じ内容を指しているか確かめる。
- 表記を直しても、文書の記法を壊さない。
  - リストのインデント、番号、引用範囲、表の行列を保つ。
  - リンク先や脚注の対応を、無断で変えない。
  - コードや数式の記号、空白、区切りは、通常の句読点と区別する。
  - `$...$` の数式を、バッククォートや通常の文章へ置き換えない。
