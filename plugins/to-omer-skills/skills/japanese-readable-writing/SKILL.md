# 意味と構成を保ち、日本語の表現を整える

## 扱う範囲

- 読者が、語句や文の関係を読み直さずに理解できる表現にする。
  - 語彙、助詞、語順、文末、表記、文同士のつながりを扱う。
  - 本文だけでなく、見出し、箇条書き、表、注記の文言も対象にする。
- 情報の採否、説明順、階層、表示形式を決める規則は設けない。
  - 形式や構成の指定に従い、推敲だけの依頼では原稿の構成を保つ。
  - 地の文にも箇条書きにも適用し、どちらかへ一律に変えない。
  - 新規作成や要約でも、依頼の内容と編集範囲に沿って表現を整える。

## 他のSKILLとの併用

- `reader-first-structure` と併用する場合は、先に同SKILLで構成を整える。
  - その構成を保ちながら、本SKILLで表現を推敲する。

## 意味を変えない

- 原文と提供資料を、意味を確認する基準にする。
  - 途中稿を推敲する場合も、元の資料に照らす。
  - 途中稿に含まれる誤りを、正しい内容として引き継がない。
- 指定された変更を除き、次の内容を保つ。
  - 事実、数値、単位、日時、主体、対象、引用、識別子
  - 条件、例外、否定の範囲、何を数えているか
  - 義務、禁止、推奨、許可、予定、推測の違いと確信度
  - 時制、因果関係、手順や出来事の意味上の順序
  - 筆者の立場や評価、発言者の区別、意図された語り口
  - 仮定や架空の例なのか、実際の報告なのかという区別
- 日本語の推敲を、情報を削る許可とみなさない。
  - 要約を求められた場合も、条件や限定を落として断定を強めない。
  - 一部だけの要約や変更の指定を、文書全体へ広げない。
- 自然に言い換えるために、未知の内容を補わない。
  - 主体、理由、定義、期限、具体例を勝手に作らない。
  - 文脈から意味を決められない場合は、曖昧な点を一方に決めつけない。
  - 確認が必要なら、何が不明かを本文とは別に伝える。

## 構成を保って直す

- 語句を直す前に、前後の文と親子項目を読んで関係を確かめる。
  - 一項目だけの自然さを優先して、条件や指示語の掛かり先を変えない。
- 自然に読める短文は、そのまま残す。
  - 語尾を変えるためだけに、文や項目をつながない。
  - 要点と理由を選んで読める配置を、長い一文にまとめ直さない。
- 表現の推敲では、必要な箇所だけ文を分けたりまとめたりする。
  - 分割や統合の前後で、主体、条件、因果関係を照合する。
  - 語句だけでは直せない問題は、関係する前後や親子項目まで直す。
  - 構成を保つために、明らかな意味の誤りまで残さない。
- 形式を保つことと、文字列を固定することは区別する。
  - 見出しやラベルも、役割と意味を保って自然に言い換える。
  - 引用、コード、数式の内部は、変更を求められない限り保つ。

## 推敲する

1. 依頼の読者、文体、編集範囲を確かめる。
2. [日本語の表現](references/japanese-style.md)に沿って、全文を見直す。
3. 修正後の文章を原文・資料と照合し、意味の変化を確認する。
4. 最後に完成文だけを読み、自然に理解できるか確かめる。

- 文だけでなく、前後のつながりも点検する。
  - 指示語の指す内容や、条件の掛かる範囲が分かるか。
  - 短くした結果、必要な主語、助詞、限定を落としていないか。
- 見出し、親項目、表の文言も読み直す。
  - 期限、対象、平均などの限定を、詳しい説明にだけ残していないか。
  - 要点と補助説明を分けた箇所が、不必要に統合されていないか。
- 修正の影響が及ぶ箇所も確認する。
  - 同じ用語を使う文、指示語で受ける文、対応する見出しや表を確かめる。
  - 文字列の検索だけで済ませず、長い文書の後半も全文を読む。
- 自然な表現には、直した形跡を残すためだけの変更を加えない。
  - 意味の誤りや読みにくさと、文体の好みを分ける。

判断に迷う箇所は、[推敲の例](references/anti-patterns-and-examples.md)で確かめる。
参照資料と適用範囲は、[根拠と適用範囲](references/research-basis.md)にまとめている。

## 出力

- 推敲では、依頼された完成文を出す。
  - レビューでは、問題と修正案を影響の大きい順に示す。
  - 改稿や変更説明は、依頼された範囲で行う。
- 文書そのものに、納品の案内や作業経緯を混ぜない。
  - 点検記録、自己評価、このSKILLを使った説明も、求められた場合にだけ出す。
  - 読者に必要な出典、前提、不確実性は、文書の内容として残す。
