# 書き分けの例

- 以下は、この記法を説明するための作例である。
  - 実在の製品・規約・実験結果ではない。
  - 一部の例は、提供された補足検証の題材を短くしたものである。
  - 原文にない理由や条件を補ってよい、という例ではない。

## 長い一文から、要点と理由を分ける

**材料**

> 月額費用が予算内であり、担当者が不在でも定時に集計できるため、毎日の集計にはA案を採用するが、A案は臨時実行に対応していないので、突発的な集計は今回の対象に含めない。

**構成例**

- 毎日の集計には、A案を採用する。
  - 月額費用は予算内に収まる。
  - 担当者が不在でも、定時に集計できる。
- 突発的な集計は、今回の対象に含めない。
  - A案は臨時実行に対応していない。

**判断の要点**

- 案の採用と対象範囲の決定は、どちらも主な判断なので同じ階層に置いた。
  - 各判断を支える理由は、その下に残した。

## 箇条書き記号だけを付けない

**分割が足りない例**

- 毎日の集計にはA案を採用するが、これは予算内であり、担当者が不在でも定時に集計できるためで、臨時実行には対応しないので突発的な集計は対象外とする。

**同じ階層に並べただけの例**

- 毎日の集計にはA案を採用する。
- 費用は予算内である。
- 担当者が不在でも集計できる。
- 突発的な集計は対象外とする。
- A案は臨時実行に対応していない。

**判断の要点**

- 最初の例では、文の途中まで読まないと要点を読み取れない。
- 次の例では、判断と理由が同じ重要度の情報として並んでいる。
- 前節の構成例なら、主な判断を先に読み取れる。
  - 必要なら、その判断の理由も読める。

## 条件を子項目だけに書かない

**材料**

> 予約日時は、利用日の前日17時までなら無料で変更できる。それ以降は変更できない。

**誤読を招く例**

```markdown
- 予約日時は無料で変更できる。
  - 利用日の前日17時までに限る。
```

**構成例**

- 予約日時は、利用日の前日17時まで無料で変更できる。
- 利用日の前日17時を過ぎると、予約日時は変更できない。

**判断の要点**

- 「無料」という結論だけを独立させない。
  - 期限後の扱いも、同じ階層に残す。
- 条件が二つある場合は、組み合わせ方も示す。

```markdown
- 次の2条件を両方満たす場合に申請できる。
  - 利用者登録が完了している。
  - 未返却の機器がない。
```

- この親項目を読むだけでは、申請できるかは判断できない。
  - 判断するには、二つの子項目を読む必要がある。
  - 「誰でも申請できる」とは誤解させない書き方になっている。

## 平均の変化を、全員の変化にしない

**材料**

> 架空の調査で、設定を使った12人の集中しやすさの自己評価は平均2.8から3.6になった。改善した人が多かったかは、この平均値だけでは分からない。

**限定が伝わりにくい例**

```markdown
- 設定を使った12人では、集中しやすさの自己評価が上がった。
  - 平均は2.8から3.6になった。
```

**構成例**

- 設定を使った12人では、集中しやすさの自己評価の平均が上がった。
  - 平均は2.8から3.6になった。
- 改善した人が多かったかは、この平均値だけでは分からない。

**判断の要点**

- 親項目にも「平均」を残し、平均値の変化だと分かるようにした。
  - 平均値と、個々人の変化や人数の割合を取り違えない。

## 条件をまとめても、数える対象を変えない

**材料**

> 架空の復元手順では、赤い鍵、監査保留、番号不一致のどれかがあれば開始しない。赤い鍵と監査保留は管理係へ、番号不一致は記録係へ連絡する。複数の禁止条件に当てはまれば両係へ連絡する。

**範囲を狭める整理**

- 両方の連絡先に関わる条件があれば、両係へ連絡する。

**構成例**

- 赤い鍵、監査保留、番号不一致のどれかがあれば、開始しない。
- 複数の禁止条件に当てはまる場合は、両係へ連絡する。
- 一つだけの場合は、その条件に対応する係へ連絡する。
  - 赤い鍵または監査保留なら、管理係へ連絡する。
  - 番号不一致なら、記録係へ連絡する。

**判断の要点**

- 数えるのは、連絡先ではなく禁止条件である。
  - 赤い鍵と監査保留だけでも、二つの条件に該当する。
  - この場合も、材料にある条件どおり、両係へ連絡する。

## 否定する対象を広げない

**材料**

> 架空の映像実習では、毎秒のコマ数が異なる映像に、今回の60という差だけをそのまま当てはめる方法は扱わない。

**範囲を広げる整理**

- 毎秒のコマ数が異なる映像への適用は、扱わない。

**構成例**

- 毎秒のコマ数が異なる映像に、今回の差60だけを直接使う方法は扱わない。

**判断の要点**

- 扱わないのは、特定の方法である。
  - コマ数が異なる映像への適用全般を、対象外にしない。

## 二つの前提を、正しい結論につなぐ

**材料**

> A案もB案もCSVを出力できる。今回比較するのはCSV出力の可否だけなので、この条件では両案とも要件を満たす。

**誤った親子関係**

```markdown
- A案はCSVを出力できる。
- B案はCSVを出力できる。
  - 両案とも要件を満たす。
```

**構成例**

- CSV出力の可否では、両案とも要件を満たす。
  - A案はCSVを出力できる。
  - B案もCSVを出力できる。

**判断の要点**

- 両方の前提を、結論の下にそろえた。
  - 性能や価格まで同じだとは判断しない。

## 手順の順序と、共通の条件を保つ

**材料**

> 架空機器を拭き終わったら、布の繊維が残っていないか目視する。残っていれば取り除き、もう一度確認する。問題がなければケーブルを接続し、電源を入れる。

**共通の条件が伝わりにくくなる例**

```markdown
1. 問題がなければ、ケーブルを接続する。
2. 電源を入れる。
```

**構成例**

1. 布の繊維が残っていないか、目視する。
2. 繊維が残っていれば、取り除いてもう一度確認する。
3. 問題がなければ、ケーブルを接続して電源を入れる。

**判断の要点**

- 「問題がなければ」は、接続と電源投入の両方に掛かる。
  - この二つの操作は短いので、条件とともに一項目にまとめた。
- 長くて分ける場合は、共通の見出しか各項目に条件を示す。
  - 先頭の操作だけに条件を付けて、残りの操作を無条件に行うように書かない。
- 操作の順序は、同じ階層の番号で示す。
  - 次の工程を、補足として子項目にしない。

## 言葉の断片へ分けない

**細かすぎる例**

```markdown
- A案は
  - 費用が
    - 予算内なので
      - 採用する。
```

**構成例**

- A案を採用する。
  - 費用が予算内に収まる。

**判断の要点**

- 一つの文を読み終えるためだけに、階層をたどらせない。
  - 判断と理由を、それぞれ意味が通る短文にする。

## 因果関係も、短文の階層箇条書きで説明できる

**材料**

> 同じ入力には保存済みの結果を返すため、再計算が不要になり、処理量を減らせる。ただし、入力が毎回違う場合は保存済みの結果を再利用できない。

**構成例**

- 同じ入力が繰り返される場合、処理量を減らせる。
  - 同じ計算を繰り返す必要がない。
    - 保存済みの結果を返せるためである。
- 入力が毎回違う場合、結果を再利用できない。

**判断の要点**

- 因果関係があるだけで、長い段落へ戻す必要はない。
  - 結果と理由の関係を、言葉でも示す。

## 推論の途中を示し、必要なら地の文でつなぐ

論証全体ではなく、式を変形する箇所だけを示す。

**材料**

> 正の整数 $a$ と $b$ について、$\sqrt{2} = \frac{a}{b}$ と仮定する。両辺を二乗すると、$a^2 = 2b^2$ になる。

**一段ずつ示す形**

- $\sqrt{2} = \frac{a}{b}$ から、$a^2 = 2b^2$ が得られる。
  1. 両辺を二乗し、$2 = \frac{a^2}{b^2}$ を得る。
  2. 両辺に $b^2$ を掛け、$a^2 = 2b^2$ を得る。

**地の文を残す形**

- $\sqrt{2} = \frac{a}{b}$ から、$a^2 = 2b^2$ が得られる。

  両辺を二乗すると、$2 = \frac{a^2}{b^2}$ となる。両辺に $b^2$ を掛けると、$a^2 = 2b^2$ になる。

**判断の要点**

- 材料の式から分かる、途中の計算操作を明示した。
  - 新しい前提や、別の結論は足していない。
- 番号を振るだけでは、省略された操作は伝わらない。
  - 一段ずつ確認するなら、番号付きにできる。
  - 続けて変形を追うなら、短い地の文にできる。

## 語りの間合いを保つ

**材料と依頼**

> 語り口を残して整える。「聞こうと思った。でも、聞かなかった。翌日も、聞かなかった。」

**残す形**

> 聞こうと思った。でも、聞かなかった。翌日も、聞かなかった。

- この反復は、ためらいと時間の経過を表している。
  - 内容を一覧にすると、語りの働きが変わる。
- 文章の内容を分析する依頼なら、別に箇条書きで説明できる。
  - 語りそのものの推敲と、内容の分析を混ぜない。

## 表は、同じ観点で並べて比べるときに使う

**材料**

> Aは月500円で共同編集不可、Bは月800円で共同編集可。保存容量はどちらも10GB。

| 比較する点 | A案 | B案 |
|---|---|---|
| 月額費用 | 500円 | 800円 |
| 共同編集 | できない | できる |
| 保存容量 | 10GB | 10GB |

- 同じ観点で両案を比べる部分は、表にできる。
  - 選ぶ理由は、表とは別の短い箇条書きで説明する。
- 比較の観点がそろわない説明まで、表にまとめない。
  - 箇条書きを基本にする方針は、表を使っても変わらない。
