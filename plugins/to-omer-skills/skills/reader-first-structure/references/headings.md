# 見出しで、読める内容を示す

## 見出しとラベルの役割

- 文書の題名：主題と、何を調べられる文書かを示す
  - 例：申請案内：対象者と提出手順
  - 本文にない網羅性や優位性をうたわない
- 章・小節の見出し：その中の具体的な話題を示す
  - 章の例：申請書を提出する
  - 小節の例：窓口で提出する
  - 専門名が必要なら残し、その用途を予測できるようにする
- 項目内のラベル：近くの説明を読み分ける
  - 申請条件を分けるなら、「初めて申請する場合」「再申請の場合」でよい
  - 短い項目すべてを小見出しにせず、独立して探す長い説明を見出しで区切る

## 名前と内容をそろえる

- 見出しの段は、話題の包含関係で決める
  - h2を結論、h3を理由などの役割に固定しない
  - 字を小さくするためだけに段を下げない
- 見出しと、その下の内容を照合する
  - 「提出できる時間」の下に提出場所もあるなら、置き場所か見出しを見直す
  - 読者が探す対象の違いを、抽象的な「詳細」「その他」で隠さない
- 見出しだけで未知の結論を理解させようとしない
  - 定義を学ぶ節では、対象や問いを示し、前提を説明してから結論へ進む
  - 既知の用語を使う報告なら、結論を見出しにできる
  - 索引では、正式名称だけの方が探しやすい場合もある
- 見出し直後に、同じ要点を毎回書き足さない
  - 見出し・導入・親項目が同じ内容なら、重複する案内を減らす
  - 前の説明との関係が必要なら、その接続を短く示す

## 読み直し

1. 見出しだけで、その場所の内容を予想する
2. 本文と照合し、ずれていれば名前と置き場所の両方を検討する
3. 同じ階層の見出しを並べ、上位の見出しが示す範囲に収まるか確かめる
